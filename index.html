About Me

I am a final-year Computer Science undergraduate at the University of Engineering and Technology (UET) Taxila, Pakistan, and currently work remotely as an Edge AI Research Engineer at Duke Kunshan University's Edge Intelligence Lab under the supervision of Associate Professor Bing Luo.

My research focuses on on-device machine learning inference, mobile systems engineering, and edge AI reliability. Rather than focusing exclusively on cloud-scale model training, my work concentrates on running, benchmarking, and fine-tuning models reliably on consumer edge hardware. I write low-level C and C++ native bridges (via JNI and dart:ffi) into inference runtimes such as llama.cpp and libmtmd, manage tensor memory manually, and build automated fault injection pipelines to study how models behave under severe hardware degradation and resource constraints.

My undergraduate thesis introduces AURAF (Adaptive Unified Runtime Architecture for Flutter), a system designed to unify token budgeting, edge/cloud fallback strategies, and hardware-aware runtime execution for cross-platform mobile applications.

Muhammad Assad Ullah
Zenodo Research Preprint, 2026

Abstract: Evaluating on-device deep learning reliability typically treats fault injection and observability as independent stages. This paper introduces an integrated methodology combining automated mutation and memory fault injection with millisecond-granularity process telemetry. SATE AI: A Fault Injection and Reliability Engineering Framework for On-Device AI Models
Muhammad Assad Ullah
Zenodo Research Manuscript (Prepared for JOSS / arXiv submission), 2026
[DOI] [Zenodo] [Code]
Abstract: SATE AI is an open-source reliability engineering framework specifically designed for on-device machine learning models. It provides 11 systematic fault injectors (covering memory exhaustion, input corruption, latency jitter, and hardware throttling) across 8 model adapters including ONNX Runtime, TensorFlow Lite, llama.cpp, and MediaPipe. The framework executes an automated 246-case verification matrix to profile boundary failure modes in resource-constrained environments.

Systems & Software

  • SATE AI
    Fault-injection and chaos engineering toolkit for on-device artificial intelligence. Features 11 fault injectors, 8 runtime adapters (ONNX, TFLite, llama.cpp, MediaPipe), 246 automated test cases, and a 160/160 pub.dev quality rating with 9 published releases.
  • EdgePulse
    Lightweight telemetry SDK for on-device inference. Captures real-time resident memory, battery drain, thermal throttling, and CPU utilization traces on physical Android and iOS devices.
  • u2_flutter
    Flutter UI automation driver extending openatx/uiautomator2 (7.8k stars) to enable automated testing on Flutter mobile applications. Listed in upstream repository via PR #1196, published on PyPI, and adopted by East China Normal University.
  • MobileFineTuner
    On-device parameter-efficient fine-tuning (PEFT/LoRA) pipeline for Qwen3.5-2B vision-language models executing fully on consumer Android hardware without cloud connectivity. Developed at Duke Kunshan University.
  • AURAF Runtime Architecture
    Adaptive Unified Runtime Architecture for Flutter (BS Computer Science thesis). Provides token budgeting, hardware-aware execution, and seamless local-to-cloud fallback for mobile AI applications.
  • Offline Multimodal Vision Assistant
    Fully local Android application running Qwen3-VL-2B offline with Vulkan GPU acceleration bridges, dense visual patch embedding memory layouts, and zero external network dependencies.
  • Kea2 Flutter GUI Testing
    Integrated Flutter testing extensions into the Kea2 GUI testing benchmark developed by the FSE research group at East China Normal University (merged PRs #229 to #234).
  • AndroTest24 Flutter Benchmark
    Flutter application support extensions for the AndroTest24 GUI testing benchmark suite (ASE 2024 artifact repository; PR #2 merged, PR #4 under review).
  • LitRun Embedded Linux AI Runtime
    Embedded Linux runtime system with an interactive web fleet and cluster management dashboard for edge AI deployments.
