### 🔬 Research & Specialization
I work at the intersection of **on-device machine learning inference**, **mobile systems engineering**, and **edge AI reliability**. My work focuses on running, benchmarking, and fine-tuning quantized LLMs directly on consumer mobile hardware:
- **On-Device VLM Fine-Tuning**: Engineered an on-device training pipeline for Qwen3.5-2B using PEFT/LoRA on consumer Android hardware with zero cloud dependencies.
- **Low-Level Native Interop**: Authored custom C/C++ JNI and `dart:ffi` bindings into `llama.cpp` and `libmtmd`, with manual tensor memory management and Vulkan GPU acceleration bridges.
- **Reliability & Fault-Injection**: Creator of **SATE AI**, an automated framework evaluating model resilience under memory pressure, latency spikes, and thermal throttling.
